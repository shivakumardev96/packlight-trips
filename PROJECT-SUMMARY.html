3. Deployment Process

Step 1: Push Code to GitHub

# Initialize git repository
git init

# Add all files
git add .

# Commit
git commit -m "Initial commit - PackLight Trips website"

# Set branch to main
git branch -M main

# Add remote with token
git remote set-url origin https://@github.com/shivakumardev96/packlight-trips.git

# Force push to GitHub
git push -u origin main --force

Step 2: Deploy on Vercel

  1. Go to vercel.com and sign up with GitHub
  2. Click "Add New..." → "Project"
  3. Find packlight-trips repository
  4. Click "Import"
  5. Click "Deploy"
  6. Wait 1-2 minutes for deployment to complete
Live URL: https://packlight-trips.vercel.app

How to Connect Custom Domain to Vercel

  1. Buy domain from registrar (GoDaddy, Namecheap, etc.)
  2. Go to Vercel → Project Settings → Domains
  3. Type your domain and click "Add"
  4. Add DNS records at your registrar:
    • A record: 76.76.21.21
    • CNAME: cname.vercel-dns.com
  5. Wait 5 min - 24 hours for DNS propagation
  6. SSL certificate is automatic and free
